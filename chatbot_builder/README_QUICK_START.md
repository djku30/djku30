# 🚀 Quick Start - Chatbot Builder per Windows

## 📥 **Scarica e Avvia in 3 Passi**

### **1️⃣ Scarica il Progetto**

**Opzione A - Download ZIP (Più Facile):**
1. Vai su: https://github.com/djku30/djku30
2. Click sul pulsante verde **"Code"**
3. Click su **"Download ZIP"**
4. Estrai lo ZIP sul Desktop
5. Entra nella cartella: `djku30-main\chatbot_builder`

**Opzione B - Con Git:**
```cmd
git clone https://github.com/djku30/djku30.git
cd djku30\chatbot_builder
```

---

### **2️⃣ Setup (Solo la Prima Volta)**

Doppio click su: **`setup.bat`**

Questo installerà tutto automaticamente!

**Requisiti:**
- Windows 10/11
- Python 3.7+ (il setup ti dirà se manca)
- Connessione internet (per scaricare Flask)

---

### **3️⃣ Avvia l'Applicazione**

Doppio click su: **`start.bat`**

Il browser si aprirà automaticamente su `http://localhost:5000`

---

## 🎨 **Cosa Puoi Fare**

### 🌐 Crea Siti Web
- Click su "Sito Web" nella sidebar
- Scrivi: *"Crea un portfolio moderno"*
- Download dei file HTML/CSS/JS

### 💻 Crea App Windows
- Click su "App Windows"
- Scrivi: *"Crea una calcolatrice"*
- Download del file Python

### 💾 Salva i Tuoi Bot
- Tutti i progetti salvati in "I Miei Bot"
- Riutilizzali quando vuoi!
